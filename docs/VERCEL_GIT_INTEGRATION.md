# Vercel Git Integration

The production deployment for Fruit Tank Academy is connected to this repository through Vercel Git Integration.

- Repository: `ALLENYEUNG365/Fruit-Tank-Spelling-Game`
- Production branch: `main`
- Vercel project: `fruit-tank-academy`
- Production host: `https://fruit-tank-academy.vercel.app/`

## Deployment flow

```text
GitHub main
    ↓
Vercel Git Integration
    ↓
Production build
    ↓
fruit-tank-academy.vercel.app
```

GitHub remains the canonical source of code and migrations. Vercel is the production delivery layer.

Verified after connecting the repository to the existing Vercel project on 2026-09-14.
